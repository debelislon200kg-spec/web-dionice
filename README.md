# Dionice sažeto

Samostalni javni frontend za kratke vijesti o investiranju, dionicama i globalnim financijskim tržištima.

## Lokalni razvoj

```bash
pnpm install
pnpm run dev
```

Frontend u produkciji koristi API deployment `https://dionice-sazeto-api-server.vercel.app`.

## Vercel

Repozitorij je spreman za Vercel. Build command je `pnpm build`, a output directory `dist`.
